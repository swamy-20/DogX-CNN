📌 Project Overview
DogX CNN is a Digital Image Processing (DIP) project that classifies dog breeds from images using Convolutional Neural Networks (CNN).
The system processes dog images using image preprocessing techniques and extracts visual features such as shape, texture, and patterns to accurately identify the breed.
The project is implemented and executed using Google Colab, which provides a cloud-based environment for running deep learning models.

🎯 Objectives
Identify dog breeds from images
Apply Digital Image Processing techniques
Use CNN models for feature extraction
Improve accuracy with data augmentation

⚙️ Tech Stack
🐍 Python – Core programming language
👁 OpenCV – Image preprocessing and manipulation
🧠 TensorFlow / Keras – CNN model development and training
🔢 NumPy – Numerical computations and data handling
📊 Matplotlib – Visualization of training results
☁️ Google Colab – Cloud environment used to train and run the model

▶️ Run in Google Colab
